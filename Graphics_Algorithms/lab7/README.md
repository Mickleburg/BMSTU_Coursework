# Лабораторная работа № 7

## Тема

Оптимизация приложений OpenGL.

## Цель работы

Изучение эффективных приемов организации приложений и оптимизации вызовов OpenGL.

## Основа работы

В качестве основы взята [лабораторная работа №6](../lab6). Сохранены:

- икосаэдр как основной объект сцены;
- несколько источников света;
- процедурная текстура;
- движение объекта с абсолютно упругим отражением от границ ограничивающего объема;
- переключение каркасного и твердотельного отображения.

## Использованные оптимизации

| № | Оптимизация | Применение в программе |
|---:|---|---|
| 1 | Дисплейные списки | геометрия основного и контрольного икосаэдров компилируется в `glNewList` и выводится через `glCallList` |
| 2 | Массивы вершин | вершины, нормали и текстурные координаты хранятся в массивах и выводятся через `glDrawArrays` |
| 3 | Предварительный расчет геометрии | вершины, нормали и текстурные координаты считаются один раз при запуске, а не на каждом кадре |
| 4 | Mipmap-текстура | для процедурной текстуры строится mipmap-цепочка через `glGenerateMipmap` |
| 5 | Сокращение переключений состояния | включение/выключение освещения и текстуры выполняется только при реальном изменении состояния |

Обязательные оптимизации из задания: **дисплейные списки** и **массивы вершин**. Дополнительно реализованы предварительный расчет геометрии, mipmap-текстура и уменьшение лишних изменений состояния OpenGL.

## Замеры производительности

## Управление

| Клавиша | Действие |
|---|---|
| `←` / `→` | поворот сцены вокруг оси `Oy` |
| `↑` / `↓` | поворот сцены вокруг оси `Ox` |
| `W` / `S` | приблизить / отдалить камеру |
| `+` / `-` | увеличить / уменьшить масштаб основного объекта |
| `F` | переключить каркасное и твердотельное отображение |
| `T` | включить / выключить текстуру |
| `Space` | пауза / продолжение анимации |
| `R` | сбросить положение, скорость и вращение объекта |
| `1` / `2` / `3` | включить / выключить источники света |
| `B` | показать / скрыть ограничивающий объем |
| `M` | выполнить замер производительности |
| `7` | режим `glBegin/glEnd` |
| `8` | режим массивов вершин |
| `9` | режим дисплейных списков |
| `Esc` | выход из программы |

## Структура программы

| Функция | Назначение |
|---|---|
| `build_mesh` | предварительная подготовка вершин, нормалей и текстурных координат |
| `draw_mesh_array` | отрисовка через массивы вершин |
| `compile_mesh_list` | создание дисплейного списка |
| `draw_icosahedron` | выбор режима отрисовки: `glBegin/glEnd`, массивы или дисплейные списки |
| `measure_mode` | измерение среднего времени кадра для одного режима |
| `run_benchmark` | формирование таблицы результатов производительности |
| `update_animation` | обновление движения объекта |
| `key_callback` | обработка клавиатурного управления |
