## Сборка и запуск

Нужны LLVM MinGW с OpenMP, Microsoft MPI Runtime и SDK. Скрипт `build.ps1`
ищет компилятор в стандартных каталогах/WinGet, собирает программы с `-O2`
и копирует `libomp.dll` рядом с EXE. Бинарники создаются сборкой.

Из папки `lab2`:

```powershell
.\build.ps1
$env:OMP_NUM_THREADS = 4
.\solver_openmp.exe --n 1000 --eps 1e-5 --task known
& "C:\Program Files\Microsoft MPI\Bin\mpiexec.exe" -n 4 .\solver_mpi.exe --n 1000 --eps 1e-5 --task known
```

Параметры: `--n N`, `--eps EPS`, `--max-iter K`, `--task known|random`.
По умолчанию: N=1000, eps=1e-5, max-iter=100000, `known`.
Режим `random` задаёт детерминированное решение `sin(2*pi*i/N)`.
Код возврата 2 означает, что точность не достигнута.

## Измерения

В `results` сохранена серия для N=16000, eps=1e-12, `known`, по одному запуску
каждого сочетания реализации и числа работников. Во всех десяти запусках:
263 обновления, невязка `4.639824613892e-13`, ошибка `8.618661340165e-13`.
При 16 работниках: MPI — 16.415114 с, OpenMP — 15.670640 с.
Таблицы, ускорение, эффективность и ограничения эксперимента — в отчёте.

```powershell
.\benchmark.ps1
python plot.py
```

Для графика нужен `matplotlib`. Новая серия перезаписывает `results`.
Рисунки в `images` зафиксированы для сохранённой серии: после новых замеров
их нужно обновить вместе с таблицами в `report.tex`.
